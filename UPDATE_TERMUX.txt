CẬP NHẬT ĐẢO ĐỘNG ULTRA v3.1

1. Giải nén ZIP này vào thư mục dự án Git đã clone.
2. Chạy:
   git add -A
   git commit -m "Upgrade Dao Dong Ultra v3.1"
   git push origin main
3. Mở GitHub Actions và đợi workflow “Tạo APK Đảo động v3.1” chạy xong.
4. Tải Artifact “Dao-dong-Android-APK-v3.1”, giải nén và cài app-debug.apk.

Ghi chú quyền: không cần Trợ năng/TalkBack. Cần Hiển thị trên ứng dụng khác để tạo lớp nổi và Truy cập thông báo để hiển thị/thao tác thông báo. Trả lời nhanh chỉ hoạt động với thông báo có RemoteInput. Nút Xóa tất cả chỉ xóa các thông báo do Đảo động theo dõi.
