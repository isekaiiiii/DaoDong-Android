AYANE DYNAMIC ISLAND ULTIMATE 2.7.0 — CẬP NHẬT BẰNG TERMUX

1) Tải Ayane_Dynamic_Island_v2.7_Source.zip vào Download.
2) Mở Termux và vào repository hiện có:
   cd ~/DaoDong-Android-v3
3) Kiểm tra thay đổi cục bộ trước khi đồng bộ:
   git status --short
   Nếu còn thay đổi bạn muốn giữ, hãy commit chúng trước. Không dùng git reset --hard.
4) Lấy commit mới nhất từ GitHub:
   git fetch origin
   git pull --rebase origin main
5) Giải nén bản v2.7 đè lên project hiện tại:
   unzip -o ~/storage/downloads/Ayane_Dynamic_Island_v2.7_Source.zip -d "$PWD"
6) Kiểm tra và đẩy bản cập nhật:
   git status --short
   git add -A
   git commit -m "Upgrade Ayane heads-up notifications 2.7"
   git push origin main
7) Vào GitHub > Actions. Chờ workflow "Tạo APK Ayane Dynamic Island 2.7 · Heads-up" chạy thành công.
8) Tải Artifact "Ayane-Dynamic-Island-APK-v2.7", giải nén và cài app-debug.apk.

HÀNH VI THÔNG BÁO MỚI
- Khi tin nhắn mới đến, đảo động tự bật ra quanh camera; có thể tự mở rộng để hiện nội dung và trả lời nhanh.
- Mặc định tự thu gọn sau 5 giây; có thể chỉnh 3–12 giây trong ứng dụng.
- Không ghim danh sách thẻ thông báo cố định trên màn hình.
- Thông báo gốc vẫn nằm trong khay thông báo Android; hết thời gian xem trước không tự xóa thông báo.
- Chạm để mở rộng thủ công hoặc bắt đầu trả lời sẽ hủy tự thu gọn trong lúc tương tác.

LƯU Ý
- Trả lời nhanh cần ứng dụng nguồn hỗ trợ RemoteInput.
- Tên/ảnh đại diện người gửi phụ thuộc dữ liệu do ứng dụng nguồn cung cấp.
- Chưa thể xác nhận build thực tế cho đến khi GitHub Actions chạy xong.
