AYANE BLOSSOM ULTIMATE 2.4.0 — CẬP NHẬT BẰNG TERMUX

LƯU Ý: Tải Ayane_Blossom_v2.4_Source.zip vào thư mục Download trước khi chạy lệnh.

1) Vào Download và clone repository vào một thư mục làm việc MỚI:

cd ~/storage/downloads
git clone https://github.com/isekaiiiii/DaoDong-Android.git Ayane-Blossom-v24
cd Ayane-Blossom-v24

2) Tin cậy thư mục này với Git (tránh lỗi dubious ownership):

git config --global --add safe.directory "$PWD"

3) Xóa nội dung cũ trong thư mục clone nhưng giữ thư mục .git, rồi giải nén source v2.4:

find . -mindepth 1 -maxdepth 1 ! -name .git -exec rm -rf {} +
unzip -o ~/storage/downloads/Ayane_Blossom_v2.4_Source.zip -d "$PWD"

4) Kiểm tra các file gốc đã được giải nén:

ls -la
ls -la app

Ở thư mục gốc cần có app/, .github/, build.gradle, settings.gradle, gradle.properties.

5) Commit và đẩy source lên GitHub:

git add -A
git status --short
git commit -m "Upgrade Ayane Blossom 2.4"
git push origin main

Nếu Git hỏi Username, nhập isekaiiiii. Nếu hỏi Password, nhập GitHub Personal Access Token (PAT), không dùng mật khẩu tài khoản GitHub. Khi dán PAT, Termux không hiển thị ký tự là bình thường. Không gửi PAT cho bất kỳ ai.

Nếu git commit báo "nothing to commit", kiểm tra lại tên ZIP, vị trí tệp trong Download và cấu trúc thư mục; không tiếp tục push cho đến khi source v2.4 thực sự xuất hiện trong git status.

6) Mở GitHub Actions:
https://github.com/isekaiiiii/DaoDong-Android/actions

Chọn workflow "Tạo APK Ayane Blossom 2.4". Sau khi có dấu tích xanh, mở lần chạy mới nhất → Artifacts → tải "Ayane-Blossom-APK-v2.4". Giải nén ZIP Artifact để lấy app-debug.apk.

Nếu build lỗi, mở job "build", chọn bước có dấu X đỏ và gửi log lỗi (không gửi token hoặc thông tin bí mật).
